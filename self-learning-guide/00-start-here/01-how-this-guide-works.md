# 0.1 · How this guide works

**Time:** 10 minutes · **Before this:** nothing.

## 📖 Read

### What is a program?

A **program** is a list of instructions for a computer. The computer follows them one by
one, exactly as written. It never guesses what you meant.

Think of a recipe:

1. Boil 1 cup of water.
2. Add 1 spoon of tea leaves.
3. Add sugar.
4. Pour into a cup.

If you swap steps 1 and 4, you pour an empty pot. The computer is the same: order
matters, and every small detail matters.

### What is AI WarRoom?

AI WarRoom is the program you will build. It runs in a web browser (like Chrome), and it
answers "what if?" questions for a business:

- What if fewer customers buy than I hoped?
- What if the warehouse floods for 6 hours?

It does the maths with exact rules that you write, and then an AI helper explains the
answer in plain words.

### How code is shown

Code appears in grey boxes like this:

```python
print("Hello")
```

When the code comes from the real AI WarRoom project, there is a note above it saying
which file and which lines, for example **`accounts/models.py`, lines 1–12**. Open that
file in VS Code and you will see the same numbers on the left side.

Commands that you type into the terminal look like this:

```bash
python --version
```

Type them **exactly**, including spaces and dots, then press **Enter**.

## ⌨️ Do

Nothing to type yet. Just do these two things:

1. Make a folder on your computer called `learning` (on your Desktop or in Documents).
   Everything you build will go inside it.
2. Get a notebook (paper or digital) for your quiz answers and for questions you want to
   ask later.

## 🌟 The golden rules

1. **Go in order.** Don't skip lessons.
2. **Read the whole lesson once before you start typing.**
3. **Type the code yourself.** Copying with your eyes and fingers helps you remember.
4. **Errors are normal.** Read the error message slowly: it usually tells you the line
   number and what went wrong.
5. **Small steps.** Run your code often, after every few lines, so you know what broke.
6. **Ask "why?"** Every line has a reason. If a lesson doesn't explain one, write the
   question in your notebook.
