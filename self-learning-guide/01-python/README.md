# Part 1 · Python from zero

**Time:** about 6 hours (take breaks!) · **Before this:** [Part 0](../00-start-here/README.md).

Python is the language AI WarRoom is written in. In this part you learn only the Python
you need for the project, using one small example the whole way: **a chai stall**.

All practice files are in the [`practice/`](practice/) folder. For each lesson you will
**type the file yourself** in your own `learning` folder, run it, and compare your output
with the lesson.

## Lessons in this part (do them in order)

| # | Lesson | You will learn | Practice file |
|---|---|---|---|
| 1.1 | [Your first program](01-your-first-program.md) | Make a file, run it, `print` | `hello.py` |
| 1.2 | [Values and variables](02-values-and-variables.md) | Numbers, text, True/False, None, maths, f-strings | `values.py` |
| 1.3 | [Lists and dictionaries](03-lists-and-dictionaries.md) | Keep many values together | `lists_and_dicts.py` |
| 1.4 | [Decisions and loops](04-decisions-and-loops.md) | `if`, `for`, `while` | `decisions_and_loops.py` |
| 1.5 | [Functions](05-functions.md) | Name a recipe and reuse it | `functions.py` |
| 1.6 | [Classes and dataclasses](06-classes-and-dataclasses.md) | Blueprints for things | `classes.py` |
| 1.7 | [Files, modules and packages](07-modules-and-packages.md) | Import code; install tools with `pip` in a virtual environment | `money_tools.py`, `use_money_tools.py` |
| 1.8 | [Money with Decimal](08-money-with-decimal.md) | Why `0.1 + 0.2` isn't `0.3`, and the fix | `decimal_money.py` |

The mini project in 1.11 is a baby version of the real AI WarRoom engine, so don't skip it.

When you finish, go to [Part 2 · How the web works](../02-web/README.md).
