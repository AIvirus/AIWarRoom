# Glossary: words you'll meet, in plain English

Listed A to Z. The lesson where each word first appears is shown in brackets.

| Word | What it means |
|---|---|
| **API** | A door into a program for *other programs*. Instead of a web page, it sends data, usually JSON. (2.3) |
| **Argument / value passed** | The actual value you give a function when you call it, e.g. `120` in `profit_for_day(120)`. (1.5) |
| **assert** | In a test: "this must be true, otherwise fail". (1.10) |
| **Attribute** | A piece of data stored on an object, e.g. `raju.name`. (1.6) |
| **Backend** | The part of a website that runs on the server: Python, Django, the database. |
| **bool** | A True/False value. (1.2) |
| **Class** | A blueprint for making objects that have data and abilities. (1.6) |
| **Comment** | A line starting with `#` that Python ignores; a note for humans. (1.1) |
| **Constant** | A value that's never meant to change; written in CAPITALS, like `PLAN`. (1.11) |
| **Dataclass** | A class that mostly holds data; Python writes the boring parts for you. (1.6) |
| **Decimal** | An exact number type for money; avoids float's tiny errors. (1.8) |
| **Decorator** | A line starting with `@` that adds abilities to the function or class below it. (1.6) |
| **Dictionary (dict)** | Values stored under names (keys): `{"name": "Raju"}`. (1.3) |
| **Docstring** | A sentence in triple quotes right under `def` or `class` saying what it does. (1.5) |
| **Edge case** | An unusual input at a border (zero, empty, exactly 150) where bugs like to hide. (1.10) |
| **Exception** | Python's way of stopping with an error, e.g. `ZeroDivisionError`. (1.9) |
| **f-string** | Text starting with `f` whose `{ }` gaps are filled with values: `f"{name} sold {cups}"`. (1.2) |
| **float** | A number with a decimal point, like `6.5`. Not exact enough for money. (1.2) |
| **Frontend** | The part of a website that runs in your browser: HTML, CSS, JavaScript. |
| **Function** | A named recipe of steps you can reuse; made with `def`. (1.5) |
| **Import** | Bring code from another file or package into this one. (1.7) |
| **Indentation** | The spaces at the start of a line. In Python they decide which lines belong together. (1.4) |
| **Index** | The position of an item in a list, counting from 0. (1.3) |
| **int** | A whole number, like `120`. (1.2) |
| **List** | Values kept in order: `[110, 125, 98]`. (1.3) |
| **Loop** | Code that repeats: `for` (once per item) or `while` (as long as something is true). (1.4) |
| **Method** | A function that belongs to an object, called with a dot: `sales.append(175)`. (1.3, 1.6) |
| **Module** | One `.py` file whose code other files can import. (1.7) |
| **None** | Python's value for "nothing / not set yet". (1.2) |
| **Object** | One thing made from a class blueprint, e.g. `raju`. (1.6) |
| **Package** | A shared bundle of modules you install with pip, like Django or pytest. (1.7) |
| **Parameter** | The named slot in a function's definition, e.g. `cups` in `def profit(cups)`. (1.5) |
| **pip** | Python's tool for downloading and installing packages. (1.7) |
| **Return** | Send an answer back from a function. (1.5) |
| **Simulation** | A program that steps through time using exact rules to show "what would happen". (1.11) |
| **String (str)** | Text, written in quotes. (1.1) |
| **Terminal** | A window where you type commands instead of clicking. (0.3) |
| **Test** | A small function that checks your code gives the right answer automatically. (1.10) |
| **Traceback** | The error report Python prints. Read its last line first. (1.9) |
| **Type hint** | A note like `cups: int` or `-> str` saying what kind of value is expected. (1.5) |
| **Variable** | A name that holds a value, like a labelled jar. (1.2) |
| **Virtual environment (venv)** | A private folder of Python packages for one project. (1.7) |
