# Part 3 · Databases

**Time:** about 2 hours · **Before this:** [Part 2](../02-web/README.md).

When a program stops, its variables vanish. A **database** keeps information safe for
years, even after restarts. AI WarRoom stores every business, simulation and decision in
one.
